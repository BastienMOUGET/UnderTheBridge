UNDER THE BRIDGE
================

Under The Bridge est un proxy local pour Windows. Les applications qui
l'utilisent sortent sur Internet par la carte reseau de votre choix
(Wi-Fi ou Ethernet), quelle que soit la route par defaut de Windows.

  Adresse du proxy : 127.0.0.1, port 1080
    - en SOCKS5      : socks5://127.0.0.1:1080
    - en HTTP        : http://127.0.0.1:1080

Le proxy n'est accessible que depuis votre PC.


1. AVANT DE DECOMPRESSER
------------------------

Faites un clic droit sur le fichier zip telecharge > Proprietes, cochez
"Debloquer" en bas de la fenetre, puis OK. Decompressez ensuite.
Sans cette etape, Windows affiche "Windows a protege votre ordinateur"
au lancement (cliquez alors sur "Informations complementaires" puis
"Executer quand meme").


2. INSTALLATION
---------------

1. Double-cliquez sur install.cmd et acceptez la demande d'administrateur.
2. Si Npcap (le pilote reseau necessaire) n'est pas installe, il est
   telecharge depuis npcap.com et son assistant s'ouvre : cliquez sur
   "I Agree", "Install", puis "Finish". Les options par defaut
   conviennent.
3. La liste de vos cartes reseau s'affiche : appuyez simplement sur
   Entree. Le service prendra la carte qui vous sert a aller sur
   Internet (Ethernet ou Wi-Fi) et la suivra automatiquement.
   Pour imposer une carte precise, tapez son nom tel qu'il apparait
   dans la premiere colonne (exemples : Wi-Fi, Ethernet, Ethernet 2).
4. Repondez Entree (oui) a "Configurer Claude Code" si vous utilisez
   Claude Code.

C'est tout. L'installation a :
  - installe le service "Under The Bridge", qui demarre avec Windows ;
  - cree sur le Bureau le raccourci "Chrome (Under The Bridge)" ;
  - configure Claude Code (si vous l'avez accepte).

Pour mettre a jour : decompressez la nouvelle version et relancez
install.cmd. Votre configuration est conservee.


3. CONFIGURER VOS APPLICATIONS
------------------------------

Navigateur Chrome
  Utilisez le raccourci "Chrome (Under The Bridge)" du Bureau. Il ouvre
  un Chrome separe (profil distinct de votre Chrome habituel), dont
  tout le trafic passe par le proxy.

Firefox
  Parametres > Parametres reseau > Configuration manuelle du proxy :
  Hote SOCKS 127.0.0.1, port 1080, SOCKS v5.
  Cochez "Utiliser un DNS distant lorsque SOCKS v5 est actif".

Claude Code (terminal ou VS Code)
  Deja fait par l'installation si vous l'avez accepte. Sinon, ajoutez
  ceci dans %USERPROFILE%\.claude\settings.json :

    {
      "env": {
        "HTTPS_PROXY": "http://127.0.0.1:1080",
        "NO_PROXY": "localhost,127.0.0.1"
      }
    }

  Puis fermez et rouvrez VS Code (ou le terminal).

curl
  curl.exe -x http://127.0.0.1:1080 https://example.com

Autres programmes
  Ceux qui acceptent un proxy SOCKS5 ou la variable HTTPS_PROXY.


4. VERIFIER QUE CA MARCHE
-------------------------

Dans PowerShell :

  curl.exe -x http://127.0.0.1:1080 https://example.com

Si le service fonctionne, la commande affiche une page HTML.


5. EN CAS DE PROBLEME
---------------------

Journal du service :
  C:\ProgramData\UnderTheBridge\bridge.log

Configuration (a modifier dans le Bloc-notes lance en administrateur) :
  C:\Program Files\UnderTheBridge\bridge.conf
  Apres chaque modification, redemarrez le service. Dans PowerShell
  administrateur :
    Restart-Service UnderTheBridge

Antivirus d'entreprise ou de surveillance des comportements :
  bridge.exe peut etre bloque comme "programme recemment trouve", car
  il est peu repandu et non signe. Si le service ne demarre pas,
  l'installation s'arrete et affiche le journal : demandez a
  l'administrateur du poste
  d'autoriser C:\Program Files\UnderTheBridge\bridge.exe.
  Chaque nouvelle version peut demander une nouvelle autorisation.

Messages frequents :
  - "503 ... pas encore d'adresse IP"
      Le service attend une adresse du reseau (DHCP). Patientez quelques
      secondes. Si ca dure, verifiez que la carte choisie est bien
      connectee.
  - "BACKING_OFF" dans le journal (surtout en Wi-Fi)
      Le routeur refuse de donner une deuxieme adresse a la carte.
      Dans bridge.conf, passez en adresse fixe : mode = static, puis
      ip, mask et gateway, avec une adresse libre hors de la plage
      DHCP du routeur.
  - Le navigateur affiche DNS_PROBE_FINISHED_NXDOMAIN sur une adresse
    http://localhost:...
      Utilisez la derniere version de chrome-bridge.cmd.

Changement de reseau : rien a faire. Le service surveille la carte
  toutes les 5 secondes. Il redemande une adresse quand vous changez
  de reseau Wi-Fi ou sortez de veille, et, avec "interface = auto",
  bascule tout seul entre Wi-Fi et Ethernet. Les connexions en cours
  sont alors coupees ; les applications se reconnectent.
  Au demarrage du PC, le service attend que le reseau soit pret.

Pour plus de details dans le journal : mettez log_level = debug dans
bridge.conf, puis redemarrez le service.


6. DESINSTALLATION
------------------

Double-cliquez sur uninstall.cmd. Le service, le raccourci du Bureau
et la configuration Claude Code sont supprimes. Npcap reste installe
(Parametres > Applications pour le retirer). Vos
fichiers restent dans C:\Program Files\UnderTheBridge et
C:\ProgramData\UnderTheBridge, vous pouvez supprimer ces dossiers.
